# Hacker News pack

- `browser_read` with `data: true, op: "stories", args: { list: "best" }` gives a story list; `op: "comments", args: { id }` gives a whole thread with depth. Both work from any page on news.ycombinator.com, so there is no need to click through.
- Reading is all this pack does. Voting, posting and commenting stay with the normal tools and wait for the user's click.
